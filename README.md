# 虛擬健身教練

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->
自己平常有健身的習慣，但有時侯會怕自己的動作不對，但實際請教練不論花錢又要跑很遠，因此我想做一個虛擬健身教練，在維持動作品質的同時，量化自己的訓練成果。

### 預期功能
<!-- 列出預計實作的功能 -->
1.即時動作追蹤與品質分析。

2.紀錄訓練成果並以圖像化呈現。

3.客製化個人運動目標。

### 使用技術
<!-- 使用的語言、框架、工具等 -->
1.python

2.mediapipe(關節辨識)

3.opencv(影像)

4.NumPy (向量運算)

5.pandas、Matplotlib(圖像呈現)

### 時程規劃
<!-- 各週預計完成的進度 -->
Week7-8:熟悉套件並實作較簡單的動作(如伏地挺身)。

Week9-11:實作臥推、深蹲等較複雜動作，並確保有一定的精準度。

Week12-13:儲存訓練紀錄並以圖像化呈現。

Week 14-15：專案測試、評估完成度與Demo。

### 與課程的關聯
<!-- 你的專題可能涉及哪些資料結構或演算法概念？為什麼？ -->
1.OOP:因為會包含多個動作，所以可以建立一個Exercise的抽象父類別，並用各動作繼承。

2.向量運算:透過角度分析動作品質。

3.資料儲存:存取組數次數資料並視覺化。

## Prototype Report

### 目前進度
<!-- 完成了什麼 -->
1.即時姿態偵測系統開發：成功整合 OpenCV 與 MediaPipe Pose 模組，建構即時人體骨架追蹤系統，能精準標註全身 33 個關鍵點並繪製骨架連線。

2.動作計數邏輯實作：開發伏地挺身自動計數功能。透過計算肩膀、手肘、手腕三點間的向量夾角，並導入狀態機 (Finite State Machine) 機制，根據「向上 (UP)」與「向下 (DOWN)」的狀態轉換判定動作完整度。

3.核心穩定度偵測：加入身體水平檢查機制。藉由比對肩膀、髖部與腳踝的斜率分佈，偵測運動過程中是否出現「核心塌陷 (Core Sagging)」情形，並提供即時警告，確保計數僅針對標準動作。

### 遇到的困難
<!-- 遇到什麼問題、如何解決或打算如何解決 -->
1.開發環境配置衝突：在整合 mediapipe、numpy 與 opencv-python 時，頻繁遇到版本依賴衝突。目前已透過建立虛擬環境並逐一鎖定相容版本解決。

2.偵測穩定度優化：在特定角度或光線下，關鍵點可能發生跳動或丟失。

### 下一步計畫
<!-- 接下來要做什麼 -->
1.訓練模組化功能：實作自定義訓練計畫，支援目標組數、次數設定，並開發「組間休息計時器」以優化使用者體驗。

2.架構重構與多動作支援：將目前的程式碼以物件導向 (OOP) 進行封裝，定義抽象基類以利快速擴展深蹲、仰臥起坐等不同動作的偵測邏輯。
### 與課程的關聯
<!-- 到目前為止，你的實作中哪些部分與課程內容有關？關係是什麼？ -->
1.抽象機器：
將電腦視覺系統視為抽象機器的體現。輸入端為攝影機擷取的連續影像訊號，透過 MediaPipe 進行特徵提取與轉換，最終輸出為結構化的運動數據與計數結果。

2.錯誤處理:
容錯機制：實作 if not ret: break 確保攝影機斷線時程式能終止。數值穩定性：在角度運算的除法分母中加入極小值 $\epsilon = 10^{-6}$，防止除以零導致系統崩潰。
