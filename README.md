# 虛擬健身教練

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->
自己平常有健身的習慣，但有時侯會怕自己的動作不對，但實際請教練不論花錢又要跑很遠，因此我想做一個虛擬健身教練，在維持動作品質的同時，量化自己的訓練成果。

### 競品比較
| 類別 | 代表產品 | 優勢 | 本專案差異化 (USP) |
| :--- | :--- | :--- | :--- |
| **智慧硬體** | Mirror, Tonal | 感測器極其精準，已有部分市場 | **低硬體成本**，僅需視訊鏡頭，且運動器材還是以徒手或健身房槓鈴啞鈴為主。 |
| **行動 App** | Kaia Health | 客製化訓練、真人評估 | **強調力量訓練細節** 著重於動作品質分析。 |
| **開源專案** | AI-Fitness-Trainer | 準確度高 | **具備 OOP 擴充性**在深蹲及伏地挺身的基礎下，希望加入臥推等動作。 |

本專案核心價值 

* **動作解析**：不只是計次，透過向量運算 (NumPy) 分析關節角度，提供即時品質回饋。
* **開發結構**：採用 OOP 抽象類別設計，可擴充不同運動項目（如從伏地挺身擴充至臥推）。
* **記錄個人訓練成果**：長期記錄個人訓練組次數，量化訓練成效。

## Prototype Report

### 目前進度
<!-- 完成了什麼 -->
1.即時姿態偵測系統開發：成功整合 OpenCV 與 MediaPipe Pose 模組，建構即時人體骨架追蹤系統，能精準標註全身 33 個關鍵點並繪製骨架連線。

2.動作計數邏輯實作：開發伏地挺身自動計數功能。透過計算肩膀、手肘、手腕三點間的向量夾角，並導入狀態機 (Finite State Machine) 機制，根據「向上 (UP)」與「向下 (DOWN)」的狀態轉換判定動作完整度。

3.核心穩定度偵測：加入身體水平檢查機制。藉由比對肩膀、髖部與腳踝的斜率分佈，偵測運動過程中是否出現「核心塌陷 (Core Sagging)」情形，並提供即時警告，確保計數僅針對標準動作。

### 遇到的困難
<!-- 遇到什麼問題、如何解決或打算如何解決 -->
1.開發環境配置衝突：在整合 mediapipe、numpy 與 opencv-python 時，頻繁遇到版本依賴衝突。目前已透過建立虛擬環境並逐一鎖定相容版本解決。

2.偵測穩定度優化：在特定角度或光線下，關鍵點可能發生跳動或丟失。

### 下一步計畫
<!-- 接下來要做什麼 -->
1.訓練模組化功能：實作自定義訓練計畫，支援目標組數、次數設定，並開發「組間休息計時器」以優化使用者體驗。

2.架構重構與多動作支援：將目前的程式碼以物件導向 (OOP) 進行封裝，定義抽象基類以利快速擴展深蹲、仰臥起坐等不同動作的偵測邏輯。

## Final Report

### 專案說明
<!-- 完整描述你的專案做了什麼 -->
本專案為即時虛擬健身教練系統，透過電腦視覺與姿勢偵測技術，在不需要專業教練的情況下提供即時的動作計數與姿勢回饋。

系統使用 MediaPipe 偵測人體 33 個骨架關節點，計算關鍵關節角度來判斷動作完成與否，目前支援三種動作：

- **伏地挺身**：偵測肩-肘-腕角度，並檢查身體是否保持水平對齊
- **引體向上**：偵測下巴是否過槓，並即時監測高低肩對稱性
- **深蹲**：偵測髖-膝-踝角度，並警告膝蓋內扣與背部過度前傾

除動作偵測外，系統包含以下功能：

- **語音即時回饋**：姿勢錯誤時自動播報中文語音提示，使用 heapq 優先級佇列搭配冷卻計時器管理播報排程，非阻塞設計不影響主迴圈效能
- **手機鏡頭支援**：啟動時可選擇電腦內建攝影機或透過 IP 串流使用手機鏡頭
- **可擴充架構**：所有動作繼承共用的 `BaseExercise` 抽象類別，新增動作只需建立一個新檔案

本專案亦針對語音佇列管理進行資料結構效能分析，比較 dict 線性掃描、heapq、分桶 deque 三種實作在不同事件規模下的時間複雜度與實測耗時，並以 `benchmark_voice_queue.py` 產出量化數據與圖表。

### 使用方式
<!-- 如何編譯、執行、使用你的程式 -->
**環境建置**

**Python 版本需求**

請使用 Python **3.9 – 3.11**，建議 **3.10**。

MediaPipe 目前對 Python 3.12 以上支援不穩定，安裝時可能出現
`ERROR: Could not find a version that satisfies the requirement mediapipe` 的錯誤。

確認目前版本：
```bash
python --version
```

如果版本不符，建議使用 [pyenv](https://github.com/pyenv/pyenv)（macOS/Linux）
或 [py launcher](https://www.python.org/downloads/)（Windows）管理多版本。

Windows 安裝指定版本範例：
```bash
# 下載 Python 3.10 安裝包後，建立虛擬環境時指定版本
py -3.10 -m venv venv

# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

# 安裝套件
pip install opencv-python mediapipe numpy

# 語音套件（擇一）
pip install gtts pygame    # 推薦，中文音質較好
pip install pyttsx3        # 離線備用
```

**執行主程式**

```bash
python virtual_coach.py
```

啟動後依終端提示選擇攝影機來源（電腦或手機 IP），接著對著鏡頭做動作即可自動偵測計數。

**快捷鍵**

| 按鍵 | 功能 |
|------|------|
| `Tab` | 切換動作（伏地挺身 → 引體向上 → 深蹲） |
| `R` | 重置當前計數 |
| `M` | 語音靜音 / 取消靜音 |
| `Q` | 離開程式 |

**執行效能分析**

```bash
pip install matplotlib
python benchmark_voice_queue.py
```

執行完畢後終端會輸出各資料結構的耗時比較表，並在同目錄產生 `benchmark_chart.png` 圖表。
